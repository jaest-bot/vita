層級描述

目前僅有一名流浪者宣稱曾抵達此層級。Level c 0.8 初始呈現為一正方形臥室，無論大小，地板上總存在 1 至 3 個坐墊，本層級因此得名。

本層級幾無補給；隨流浪者在其中停留的時間增加，空間會逐漸發生扭曲與改變。數日後，房內陳設增加，並出現通向更大房間的單向入口。自第二個房間起，每次睡眠後房內陳設將隨機改變，同時開始向下延伸生成新的房間——每次生成都比前一個更大，流浪者僅能單向向下行進，無法返回上層。

數十天後，房間內的陳設開始無視重力隨機擺放，最終可能在底部空間中出現杏仁水泳池。根據日誌記錄，跳入泳池將被傳送至一處疑似並非 Level 0 本體的空間——隨後記錄者就此失聯。

Level 0.8「坐墊室」補遺

經過多次交叉比對，我們推測 Level c 0.8 並非真正的危險層級。所謂的「失蹤者」日誌，實際上可能只是流浪者在切入過程中留下的倒像。本人並未進入 Level 0.8，而是正常切入至 Level 1。留在 Level 0.8 的，只是意識的碎片與倒影。

結論： 所有危險與恐懼僅存在於倒像中，隨水波消散。當你看著水窪中的自己時，請記住——那並不是你，而只是被打碎的倒影。
